# 범위 (Scope)

> 상태: ✅ 확정 · 최종수정: 2026-08-06

## 1. 플랫폼 범위 (딜리버러블 5종)
| 딜리버러블 | 설명 | 현황 |
|---|---|---|
| `web` | 고객 웹 (Next.js 16) | 구현 진행 중 |
| `server` | 백엔드 API (Spring Boot 3.4.1) | 구현됨 |
| `android` | 고객 안드로이드 (WebView 셸 + 네이티브 하단탭) | 구현됨 |
| `admin-web` | 관리자 웹 | **신규 개발** |
| `admin-windows` | 직원용 Windows WPF 데스크톱 앱 | **신규 개발** |

> `admin-android`(관리자 안드로이드)는 **보류** — 이번 범위 제외, 후속 검토.

## 2. In-Scope

### P0 (MVP 필수)
- 프로토타입 ~17화면 웹 포팅 — **시각·구조 충실 재현**.
- 핵심 커머스 플로우: 홈 → 카탈로그 → 상품상세 → 장바구니 → 체크아웃(**mock 결제**) → 주문완료 → 주문내역.
- 웹↔백엔드 **HTTP 연동 확대**: 현재 catalog/order만 http → **review/points HTTP 승격 + 포인트 원장(PointLedger) 실도입**(고정 5000 폐기 — 가입 보너스·주문 사용·구매 적립·취소 환불).
- **JWT 인증 실제화** (현재 X-Demo-User 헤더 → 실제 로그인, User 도메인 추가).
- 안드로이드 **네이티브 네비게이션 브릿지 완성** (`window.__sswNavigate`/`onRouteChanged` → SPA 전환·탭 동기화).
- **주문 취소**(pending/paid 한정) · **쿠폰 지갑 단일화**(보유 쿠폰 기반 적용) · **찜 계정 귀속**(wishlists).

### P1
- 멀티플랫폼 쇼케이스: **매장찾기(GPS)** · 알림 서버(주문상태/프로모션 + 안드 푸시) · 파일 서버(리뷰사진/프로필 업로드).
- 관리자 웹(`admin-web`) 신규 개발.
- **배송지 관리**(user_addresses) · **1:1 문의**(고객 작성 + admin-web 관리) · **운송장 입력·배송 흐름**(tracking → 상태 전환 → 푸시).

### P2
- **만보기(걸음수) + 커머스 리워드**.
- **AI-Native 자연어 상품검색**(목업/추상화 수준).
- 직원용 데스크톱(`admin-windows`) 신규 개발.

> P0~P2 경계는 시연 데드라인이 없으므로 **완성도 기준**으로 자른다. 정확한 우선순위는 [요구사항 문서](../requirements/01-functional.md)에서 확정한다.

## 3. Out-of-Scope (이번 데모 제외)
- 실결제 PG 연동 (현재 mock 결제, status 바로 `paid`).
- 대규모 트래픽/부하 대응 (트래픽 스케일링).
- 복잡한 AI 기능: 개인화 추천·챗봇·가상피팅·음성쇼핑 (백로그·스토리용).

## 4. 시연 환경 (2026-08-06 갱신)
- 프론트 웹 2종(고객·관리자): **Cloudflare Workers**. 깃 연동 빌드가 빌드·배포를 맡는다.
- DB + 백엔드: **GCP Compute Engine**. 백엔드/DB 포트는 외부에 직접 노출하지 않는다.
- 배포 자동화: 프런트는 깃 연동 빌드, 서버는 **GitHub Actions + 키 없는 연합 인증 + 터널 SSH**. 셋 다 `main` 머지가 곧 배포다.
- 배포·운영 정리는 In-Scope, 트래픽 스케일링은 Out-of-Scope. (배포 상세 문서는 이 공개본에 포함하지 않는다)

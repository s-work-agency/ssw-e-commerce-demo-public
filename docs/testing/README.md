# 테스트 범위와 검증 현황

기준일: 2026-10-15. 테스트 도구가 있다는 것과 실제 UI·외부 연결까지 검증했다는 것은 다릅니다.
이 문서는 공개 가능한 검증 범위를 정리하며 내부 실행 경로나 설정은 포함하지 않습니다.

| 대상 | 현재 검증 기반 | 별도로 확인할 범위 |
|---|---|---|
| 서버 | JUnit·Spring/H2 통합·합성 연동 테스트 | MariaDB 경합·운영 연결·실제 migration/복원 |
| 고객·관리자 웹 | Node 회귀 테스트·TypeScript·lint | 실제 브라우저 로그인 전환·스트림·레이아웃, 배포 번들 |
| WPF | xUnit·합성 UI·가짜 HTTP/스트림 | 실제 GUI·테마/DPI·모델 왕복·패키지 실행 |
| Android | JUnit 정책 테스트 | 기기 회전·WebView 입력/경로·권한·센서·키보드 |

2026-10-15 감사의 **수정 전 기준선**은 서버 410개, 고객 웹 522개, 관리자 웹 274개,
WPF 선택 테스트 138개 통과였습니다. WPF 전체 모음의 결과가 아니며, Android 테스트는 해당 감사에서
완료하지 못했습니다. 이후 코드 수정의 합격 근거로 이 숫자를 그대로 재사용하지 않습니다.

기존 검사에서 놓친 로그인 전환·늦은 응답·스트림 중단 경계는 합성 재현으로 보완 대상으로 확인했습니다.
수정 검증에서는 실패 경로뿐 아니라 정상 갱신·동일 계정 재로그인·상담 문진의 로그인 왕복도 함께 확인합니다.

## 수정 후 로컬 검증

같은 날 후속 수정 후보를 격리된 환경에서 다시 검사한 결과입니다. 운영 배포나 실제 외부 연결의 완료를 뜻하지 않습니다.

| 대상 | 후속 결과 | 한계 |
|---|---|---|
| 서버 | 439개 통과, 배포용 JAR 빌드 성공 | 쿠폰 정책/이관 후속 검사 포함. H2·합성 경합이며 실제 MariaDB·운영 migration 별도 |
| 고객 웹 | 542개 통과, 타입·lint 통과 | 합성 HTTP/스트림·조회 관찰자 검사. 브라우저 DOM·배포 번들 별도 |
| 관리자 웹 | 286개 통과, 타입·lint 통과 | 로그인 수명·초안·좌표·통계 경로 검사. 실제 UI·외부 AI 연결 별도 |
| WPF | Release 컴파일, 전체 1,503개 통과 | 별도 설정 경로의 합성 테스트. 실제 GUI·모델 왕복 별도 |
| Android | 테스트 미완료 | 오프라인 플러그인 의존성 캐시 부족. 기기 검증도 별도 |

정상 토큰 갱신은 진행 중인 작업을 유지하고 새 로그인은 이전 개인 화면·캐시·늦은 응답과 분리하는 회귀를
추가했습니다. 쿠폰은 한번 드랍에 사용한 코드를 일반 코드 등록에서 영구 차단하는 정책으로 확정·수정했습니다.
종료·소진 후 차단과 기존 지갑 사용·취소 복원, 일반 쿠폰·가입 보상 유지도 검사했습니다. 위 수치가 모든
실환경 경계를 검증했다는 뜻은 아니며, 신규 DB migration은 아직 운영에 적용하지 않았습니다.

Playwright·Appium·FlaUI는 초기 E2E 계획에 등장한 도구입니다. 실행 근거 없이 완료된 자동화 성과로
표현하지 않습니다. 성능 요구사항의 LCP/API 지연 수치도 목표이며, 측정 환경·시점·결과와 구분합니다.

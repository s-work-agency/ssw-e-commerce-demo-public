# 사용자 스토리 (User Stories)

> 상태: ✅ 확정 · 최종수정: 2026-07-01

## 페르소나
- **고객** — 쇼핑 사용자.
- **ADMIN** — 최고관리자.
- **SELLER_SUPPORT** — 판매지원 스태프.
- **CUSTOMER_SUPPORT** — 고객·배송지원 스태프.
- **(메타) 잠재 고객사** — 시연 관람자. 이 데모의 진짜 청중.

## 고객 스토리
- **US-C1 핵심 구매 플로우**: 상품을 탐색하고 장바구니에 담아 결제(목업) 후 주문 완료·내역을 확인한다.
- **US-C2 인증·계정 귀속**: 이메일로 회원가입/로그인(JWT)하여 주문·리뷰·포인트·찜을 내 계정에 귀속한다.
- **US-C3 리뷰·포인트**: 구매 상품에 리뷰(사진 첨부)를 작성하고 포인트를 확인·주문에 사용한다.
- **US-C4 헬스 리워드**: 걸음 수가 임계에 도달하면 포인트를 적립하고, 특정 미션 달성 시 쿠폰을 받는다.
- **US-C5 위치/네이티브**: 현재 위치 기반으로 가까운 오프라인 매장을 지도에서 확인하고, 체크아웃 시 현재 위치로 배송지를 자동입력한다.
- **US-C6 AI 검색(목업)**: 복잡한 키워드 대신 일상 자연어로 검색해 상품을 추천받는다. (프론트 목업 시연)
- **US-C7 앱형·테마·알림**: 다크/라이트+accent로 앱을 꾸미고, 앱처럼 부드러운 전환으로 탐색하며, 주문 상태·프로모션을 (안드 푸시) 알림으로 받는다.

## 관리자/스태프 스토리
- **US-A1 (ADMIN) 총괄**: 전 기능에 접근하고 스태프 계정·권한(role)을 관리하며, 쿠폰/프로모션·카테고리(2-depth)를 구성한다.
- **US-A2 (SELLER_SUPPORT) 판매지원**: `admin-windows`에서 상품/재고를 대량 등록·수정하고 입점/정산 문의를 처리하며, AI 운영보조(상품설명 생성 등, 목업)로 작업을 빠르게 한다.
- **US-A3 (CUSTOMER_SUPPORT) 고객지원**: `admin-web`에서 주문/배송 상태를 관리하고 고객 문의·리뷰/클레임을 처리하며, 대시보드로 일일 현황을 확인한다.

## 잠재 고객사(시연) 스토리
- **US-D1 테스트 자동화 시연**: 시연 관람자로서 주요 시나리오가 E2E 테스트로 자동 검증되는 것을 보고, "AI가 기능뿐 아니라 품질 보증까지 구성한다"는 완성도·AX에 신뢰를 갖는다.
  - 특히 **하이브리드 앱의 웹↔네이티브 경계**(탭 → 웹뷰 → `AndroidBridge`)를 **Appium**으로 넘나들며 자동검증하는 것이 가장 강한 임팩트(업계 난제 영역).
  - 스택: 웹 **Playwright** · 안드 하이브리드 **Appium** · WPF **FlaUI** · 백엔드 **JUnit**. (05-testing, 비기능 8장 연동)

# 비기능 요구사항 (Non-Functional Requirements)

> 상태: ✅ 확정 · 최종수정: 2026-07-01

## 1. 성능 / 가용성
- 대규모 트래픽/부하 스케일링은 범위 밖 — 오토스케일링 구성하지 않음. 백엔드 단일 인스턴스 안정성 + Cloudflare CDN 캐싱으로 시연 쾌적성 확보.
- 목표치(추후 조정 가능): 웹 **LCP < 2.5s** · **API p95 < 500ms** · 이미지 최적화(next/image)·카탈로그 페이지네이션.
- `effectivePrice @Formula` 정렬 시 성능 모니터링.

## 2. 보안
- **JWT 인증**을 모든 민감 API에 강제(현재 X-Demo-User 헤더 대체).
- 파일 업로드 방어(이미지 확장자 필터링).
- **Cloudflare Tunnel** 구조 유지 — 백엔드/DB 포트 외부 직접 노출 차단. CORS 화이트리스트 유지.
- 관리자 3-role(ADMIN/SELLER_SUPPORT/CUSTOMER_SUPPORT) 최소권한 원칙.

## 3. 시각 충실도 (기준선)
- 프로토타입(`design/prototype/shop-demo`)을 **시각 기준선**으로 삼는다.
- 단, **의도적 변경은 오너 승인 하에 허용**하며 최종 검수는 오너가 한다. (하드 게이트 아님)

## 4. 앱형 UX
- 페이지 전환 애니(≈0.28s) 유지 · URL 라우트 보존 · 앱형 오버레이.
- 안드로이드는 `__sswNavigate` SPA 네비게이션으로 **탭 전환 시 전체 리로드 제거**.
  - ※ 로딩 인디케이터/스켈레톤을 없애는 게 아님 — 초기 진입·데이터 로딩 시 로딩 표현은 유지. "전체 새로고침되는 느낌"만 제거.

## 5. 반응형 / 호환성
- 모바일 우선 + 데스크톱 대응. 안드 WebView(minSdk 24)·주요 최신 브라우저.
- `admin-web`은 데스크톱 해상도 최적, `admin-windows`는 PC 대량 그리드 특화.

## 6. 관측성 / 로깅
- 백엔드 구조적 로깅 + `GlobalExceptionHandler` 표준 에러코드(INVALID_REQUEST/404/…).
- ⚠️ **시크릿 값 로그 금지**(키·경로·개수만). 프론트 에러 바운더리 + 토스트.

## 7. 데이터 재현성
- 시드 기반 데모 리셋 가능(local `DataInitializer`). prod는 별도 초기화 스크립트(prod는 DataInitializer 미실행).
- 대시보드용 주문/매출 더미데이터 시드(웹 하드코딩 금지).

## 8. 테스트 자동화 (품질 · AX 쇼케이스)
시나리오 기반 E2E 자동화를 데모의 셀링포인트로 삼는다. 멀티툴을 하나의 AI 파이프라인으로 오케스트레이션하는 것이 AX·오케스트레이션 역량의 실물 증거.

| 대상 | 도구 |
|---|---|
| 웹 콘텐츠 | **Playwright** |
| 안드 하이브리드 | **Appium** (native↔WEBVIEW 컨텍스트 전환 — 하단탭·`AndroidBridge`/`__sswNavigate`·GPS/만보기 브릿지까지 검증) |
| WPF 데스크톱 | **FlaUI** |
| 백엔드 | **JUnit** |
| (옵션) 간결 시연 플로우 | Maestro |

- **하이브리드 앱의 웹↔네이티브 경계 자동화**는 업계 난제 영역 → 잠재 고객사 대상 핵심 임팩트.
- 상세 전략은 05-testing으로 연동.

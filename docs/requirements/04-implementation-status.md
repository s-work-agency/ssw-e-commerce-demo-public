# 구현 현황과 문서 기준

기준일: 2026-10-15. 현재 로컬 소스와 보유 운영 기록을 대조한 기능 요약입니다.
소스 구현·자동 테스트·실제 연결·운영 배포는 서로 다른 상태이며, 최신 로컬 변경을 배포 완료로 표현하지 않습니다.

| 영역 | 소스에 구현된 범위 | 구분할 사항 |
|---|---|---|
| 고객 웹 | JWT·HTTP 커머스, 주문·리뷰·혜택·프로모션, 챗봇·상담 | 결제·소셜 공급자·배송사 연동은 목업. 공통 인증·파일·상담과 AI는 실제 외부 의존성 |
| 관리자 웹 | 주문·상품/재고·문의·상담·리뷰·프로모션·대시보드·사용량 관리 | 회원/역할 관리와 카테고리 자체 CRUD 전체를 제공하는 것은 아님 |
| 자연어 통계 | 고정 지표 선택·파라미터 검증·조회·해석, 추천 질문·재시도 | 관리자 웹·WPF 화면 구현. 임의 SQL이나 DB 직결이 아니며 최신 UI는 로컬 변경 포함 |
| WPF | 역할 기반 10개 메뉴·필터·다중 선택·CSV·업무 도구 | 단순 7개 탭/목업 보조 앱 설명은 과거 상태 |
| WPF AI | SIWC 또는 OpenAI 호환 연결, 조회/화면 도구, 사용량·컨텍스트·수동/자동 압축 | 최신 전환·UI는 로컬 구현 포함. 실제 연결과 릴리스는 별도 검증 |
| Android | WebView·네이티브 5탭·경로/테마 bridge·걸음 센서/권한·로딩/오류 처리 | GPS·백그라운드 걸음 서비스·Android 푸시 완성본을 주장하지 않음 |
| 서버·운영 | 커머스·통계 API, 전용 DB와 공통 Infra 역할 분리 | 운영 기록은 Pi/K3s, 웹은 Workers. 서버의 과거 VM CI와 현행 릴리스는 별개 |

## 문서 사용 방법

기획·사용자 스토리의 초기 우선순위는 완료 상태가 아닙니다. 이 표로 제공 범위를 확인하고,
[테스트 현황](../testing/README.md)에서 자동 검사와 실사용 검증의 차이를 확인합니다.
시드 데이터와 현재 운영 데이터 개수, 소스의 기본값과 실행 환경 설정도 구분합니다.

## 공개본 갱신 기준

공개 문서는 자동 미러가 아니라 검토한 변경만 반영하는 요약본입니다. 갱신할 때는 구현 상태·기준일·
상대 링크·공개 제외 정보를 다시 확인합니다. 내부 접속 정보·자격증명·개인 데이터는 옮기지 않으며,
상세 스키마와 운영 절차 전문은 공개 범위에서 제외합니다. 문서 수정 자체가 코드 배포를 의미하지 않습니다.
